# SamaHesab v2.6.0 — انتشار

> نسخهٔ کلان: گذار از **ERP یکپارچه** به **پلتفرمِ ماژولارِ ERP**. بدونِ بازنویسی — استخراجِ کنترل‌شده.

## مهم‌ترین تغییر — معماریِ ماژولار
هستهٔ ERP لاغر شد و همهٔ دامنه‌های اختیاری پشتِ قراردادِ `IModule` و اینترفیس‌های هسته‌ای از هسته جدا شدند. با غیرفعال/حذفِ هر ماژول، هسته سالم می‌ماند (removability).

**ماژول‌های استخراج‌شده (هرکدام اسمبلیِ مستقل):**
- **هتل/PMS** · **پیمانکاری** · **رستوران** · **گردشگری** · **POS** (لِینِ laptop)
- **حقوق‌ودستمزد** · **حضوروغیاب** · **باشگاه مشتریان/CRM** (لِینِ pc)

**هسته (پایدار، بازکاربردپذیر):** حسابداری · خزانه · انبار · فروش · خرید · اشخاص(پایه) · امنیت/مجوز/کاربر · چندشعبه · گزارش‌گیریِ هسته · موتورِ قالب · لایسنس · تنظیمات · لاگِ حسابرسی · اعلان.

**زیرساختِ ماژول:** `SamaHesab.Modules.Abstractions` (IModule) + بارگذاری/ثبتِ ماژولِ فعال در استارت‌آپ + کشِ مدلِ EFِ ماژول‌آگاه + اینترفیس‌های decoupling (`IAttendanceAggregateProvider`، `ISalesCommissionProvider`، `IEmployeeDependencyChecker`) تا ماژول‌ها به هم وابسته نشوند.

## بهبودهای این نسخه (از ۲٫۵٫۲۳)
- داشبوردِ هشدارهای قابل‌اقدام (چکِ سررسید، دریافتنیِ معوق، کسریِ موجودی، ودیعهٔ کمِ گردشگری) + فیلترِ نقش‌محور.
- خزانه: ثبتِ دستیِ چک (`RegisterCheque`) + تقویمِ سررسیدِ چک.
- گردشگری: واچر/کارتِ مسافر + تاریخِ سفر + لیستِ فروش با نزدیک‌ترین سفر/تعدادِ مسافر.
- رفعِ باگ: فارسیِ خوانا در لاگِ حسابرسی · فیلترِ contains کمبوی حساب در ثبتِ سند.
- کیفیت: build کاملِ سبز · ۶۱۸ تستِ خودکار.
