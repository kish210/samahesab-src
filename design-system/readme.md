# سماع‌حساب — دیزاین‌سیستم ERP

دیزاین‌سیستم سازمانی برای **سماع‌حساب** (محصول سماع رایانه کیش). هدف: حسِ یک **ERP عملیاتی ایرانی** سبک سپیدار / هلو / SAP Business One — نه داشبورد SaaS. چگالی داده بالا، کیبوردمحور، کاملاً RTL.

منبع کد اصلی محصول: **github.com/kish210/samahesab** (WPF + Telerik + .NET 9 + SQL Server). برای دقت بیشتر در ساخت دیزاین، آن ریپو را بررسی کنید.

| `--blue-900` | **#1B2843** | سایدبار |
| `--gold-500` | **#B18A5A** | طلایی — اکسنت ۵٪ |

نسبت رنگ: **۸۰٪ خنثی / ۱۵٪ برند / ۵٪ وضعیت**. بدون رنگ خارج از این پالت.

## اصول طراحی
1. ERP عملیاتی است؛ کاربر ۸–۱۲ ساعت در روز در فرم‌هاست. **بهره‌وری مهم‌تر از ظاهر.**
2. چگالی بالا، فضای خالی کم، گرید خط‌کشی‌شده.
3. کیبوردمحور: `F2` جدید · `F7` ذخیره · `F8` چاپ · `F9` قطعی · `Enter` افزودن ردیف.
4. همه‌ی مبالغ tabular + جداکننده فارسی + LTR در ستون.
5. RTL کامل با فونت **Vazirmatn**.

## فهرست فایل‌ها (مانیفست)

### فونداسیون
- `styles.css` — توکن‌ها (رنگ، تایپ، اسپیسینگ، شعاع، سایه) + ریست پایه. این فایل را consumerها لینک می‌کنند.
- `components.css` — کنترل‌های پایه: `.btn` `.input` `.select` `.badge` `.card` `.tbl` `.tabs` `.chip` `.switch` `.avatar` `.kbd`
- `screens/erp.css` — پوسته‌ی ERP فشرده + پریمیتیوهای فرم/گرید (`.gbox` `.dgrid` `.entry-strip` `.sumbar` `.st`)
- `screens/erp-shell.js` — تزریق تاپ‌بار + سایدبار + تب اسناد + نوار وضعیت (`ErpShell.mount(...)`)

### کامپوننت‌های React (`components/`)
`Button` · `Input` · `Select` · `Badge` · `Card` · `StatCard`
هرکدام `.jsx` + `.d.ts` + کارت نمایش. Namespace رانتایم: `window.DesignSystem_53d3bd`.

### کارت‌های فونداسیون (`ds/`)
`colors.html` (رنگ) · `typography.html` (تایپ) · `spacing.html` (اسپیسینگ/شعاع/سایه)

### صفحات عملیاتی (`screens/`)
میز کار · ثبت سند ⭐ · اسناد حسابداری · فاکتور فروش · انتقال بین انبار · کارت مشتری · کارت کالا · مدیریت چک · صندوق فروش POS (لمسی)
`screens/index.html` = فهرست بصری همه صفحات.

### خروجی‌ها و هندآف
- `png/*.png` — خروجی تصویری همه‌ی ۹ صفحه
- `handoff/ux-prompt.md` — سند کامل UX برای توسعه‌دهنده‌ها (توکن‌ها، الگوها، هر صفحه + کار WPF)
- `handoff/todo.rm` — تقسیم کار پیاده‌سازی WPF (Claude 1: حسابداری/انبار · Claude 2: فروش/صندوق)
