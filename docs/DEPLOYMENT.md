# راهنمای استقرار و راه‌اندازیِ سما حساب

> راهنمای نصب، پشتیبان‌گیری، فعال‌سازیِ لایسنس و عیب‌یابی برای **فروش و استقرارِ تجاری**.
> مخاطب: نصاب/پشتیبانِ فنی. (راهنمای کاربریِ روزمره: `SamaHesab-UserGuide.pdf`.)

---

## ۱) معماری

سما حساب دو ریخت دارد که روی **یک هستهٔ مشترک** (Application + Infrastructure) کار می‌کنند:

| جزء | نقش |
|---|---|
| **SamaHesab.exe** | برنامهٔ دسکتاپِ حسابداری (به DB مستقیم وصل می‌شود) |
| **SamaHesab.exe --pos / --restaurant / --waiter / --kitchen** | کلاینت‌های لمسی (از طریقِ **Web API** به سرورِ مرکزی وصل می‌شوند، نه DB) |
| **SamaHesab.API.exe** | سرورِ مرکزیِ REST/JWT (برای کلاینت‌های لمسی/چندایستگاهی) |
| **SQL Server** | پایگاه‌داده (Express یا Standard) |

- **تک‌ایستگاهی:** فقط `SamaHesab.exe` + SQL Server روی همان ماشین. (API لازم نیست.)
- **چندایستگاهی/فروشگاهی:** یک **سرور** (SQL + `SamaHesab.API` به‌صورتِ Windows Service) + چند **کلاینت** (`--pos`/`--restaurant`).

---

## ۲) پیش‌نیازها
- **ویندوز ۱۰/۱۱** یا **Windows Server**.
- **SQL Server 2019+** (Express رایگان کافی است). نمونهٔ پیش‌فرض: `.\SQLEXPRESS`.
- **.NET Desktop Runtime 9** (در صورتِ استفاده از نسخهٔ self-contained نیازی نیست).

> اسکیمای پایگاه‌داده در **اولین اجرا خودکار ساخته و مهاجرت می‌شود** (DatabaseMigrator) — نیازی به اجرای دستیِ اسکریپت نیست. نصب‌های تازه پایگاه‌داده را خودکار می‌سازند (نسخهٔ ۲.۳.۰+).

---

## ۳) نصبِ تک‌ایستگاهی (ساده‌ترین)
1. SQL Server Express را نصب کنید.
2. نصابِ `SamaHesab_Setup.exe` را اجرا کنید.
3. `SamaHesab.exe` را باز کنید.
4. **ویزاردِ راه‌اندازیِ اولیه** (اولین ورود) را تکمیل کنید: اطلاعاتِ شرکت · سالِ مالی · **تغییرِ رمزِ پیش‌فرضِ admin**.
5. در صورتِ نیاز، اتصالِ پایگاه‌داده را از پنجرهٔ تنظیماتِ اتصال اصلاح کنید (پیش‌فرض `.\SQLEXPRESS`).

ورودِ پیش‌فرض: `admin` / `admin123` — **حتماً در همان ابتدا تغییر دهید**.

---

## ۴) نصبِ سرور/کلاینت (چندایستگاهی)
### سرور
1. SQL Server روی ماشینِ سرور.
2. `SamaHesab_Server_Setup.exe`.
3. **API را به‌عنوانِ Windows Service نصب کنید** (اجرای خودکار در بوت):
   ```powershell
   # با دسترسیِ Administrator، در پوشهٔ نصب:
   .\installer\api-service.ps1 install
   .\installer\api-service.ps1 status
   ```
   (حذف: `... uninstall` · توقف/شروع: `stop`/`start`)
4. پورتِ API (پیش‌فرض `5080`) را در فایروالِ ویندوز باز کنید.

### کلاینت (صندوق/رستوران)
1. `SamaHesab_Setup.exe` روی هر ایستگاه.
2. شورتکاتِ «صندوق فروش» (`--pos`) یا «صندوق رستوران» (`--restaurant`).
3. در اولین اجرا (یا با سوییچِ `--setup`)، **آدرسِ سرور** را تنظیم کنید: `http://<IP-سرور>:5080`.
4. با نام‌کاربری/رمزِ واقعیِ صندوق‌دار وارد شوید (احراز از طریقِ API).

---

## ۵) پشتیبان‌گیری و بازیابی
- **پشتیبانِ دستی:** تنظیمات → پشتیبان‌گیری → «تهیهٔ پشتیبان» (فایلِ `.bak` در مسیرِ تعیین‌شده).
- **پشتیبانِ خودکار:** در تنظیمات فعال و بازهٔ روز را تعیین کنید (`AutoBackupEnabled`/`BackupIntervalDays`).
- **بازیابی (Restore):** تنظیمات → پشتیبان‌گیری → انتخابِ فایلِ `.bak` → «بازیابی». ⚠️ بازیابی، دادهٔ فعلی را بازنویسی می‌کند.
- **توصیهٔ تجاری:** پشتیبان را روی **درایو/شبکهٔ مجزا** نگه دارید و دوره‌ای آزمونِ بازیابی بگیرید.

---

## ۶) فعال‌سازیِ لایسنس
نرم‌افزار **آفلاین** است و با **۱۲۰ روز یا ۲۰۰ سندِ حسابداری** (هرکدام زودتر) به‌صورتِ آزمایشی کار می‌کند. وضعیت در **نوارِ پایینِ پوسته** نمایش داده می‌شود.

برای فعال‌سازیِ دائمی:
1. در پنجرهٔ **فعال‌سازی** (یا پس از پایانِ تریال)، **شناسهٔ دستگاه** را کپی کنید.
2. شناسهٔ دستگاه + نامِ شرکت (+ شناسهٔ ملی) را برای **فروشنده** بفرستید.
3. فروشنده با ابزارِ خصوصی، فایلِ **`.lic`** (امضاشده با RSA، مقیّد به همان دستگاه) صادر و ارسال می‌کند.
4. در پنجرهٔ فعال‌سازی → «بارگذاریِ فایلِ لایسنس» → فایلِ `.lic` را انتخاب کنید.

> رده‌ها: **Starter** (۱ شعبه/۳ کاربر) · **Professional** (۳/۱۰) · **Enterprise** (نامحدود). سقفِ شعبه هنگامِ ساختِ شعبه اعمال می‌شود.

---

## ۷) امنیت (توصیه‌های استقرار)
- رمزِ `admin` را در اولین اجرا تغییر دهید (ویزارد این را می‌خواهد).
- برای هر کاربر، نقش و دسترسیِ مناسب تعریف کنید (تنظیمات → کاربران/نقش‌ها).
- پس از چند تلاشِ ناموفقِ ورود، حساب موقتاً **قفل** می‌شود (محافظت در برابرِ حدسِ رمز).
- رویدادهای حساس (ورودِ ناموفق، اسناد، چک، خزانه و…) در **لاگِ حسابرسی** ثبت می‌شوند.
- نسخهٔ پشتیبان را رمزنگاری/محافظت کنید (شاملِ دادهٔ مالیِ مشتری است).

## ۸) عیب‌یابیِ سریع
| نشانه | راه‌حل |
|---|---|
| «عدم دسترسی به پایگاه داده» هنگامِ ورود | سرویسِ SQL Server روشن است؟ رشتهٔ اتصال (`.\SQLEXPRESS`) درست است؟ از پنجرهٔ تنظیماتِ اتصال آزمایش کنید. |
| کلاینتِ POS وصل نمی‌شود | آدرسِ سرور و پورتِ ۵۰۸۰، باز بودنِ فایروال، و اجرای سرویسِ `SamaHesabApi` را بررسی کنید (`api-service.ps1 status`). |
| صفحه‌ای خطای «Invalid column/object» می‌دهد | برنامه را یک‌بار ببندید و باز کنید؛ migration-runner اسکیمای DB را خودکار به‌روز می‌کند. |
| «دورهٔ آزمایشی به پایان رسید» | طبقِ بخشِ ۶ لایسنس را فعال کنید. |
| لاگ‌های برنامه | `%AppData%\SamaHesab\logs` |

## ۹) چک‌لیستِ تحویلِ مشتری (Go-Live)
- [ ] SQL Server نصب و در حالِ اجرا.
- [ ] برنامه نصب و اولین اجرا موفق (DB خودکار ساخته شد).
- [ ] ویزاردِ راه‌اندازی کامل (شرکت/سالِ مالی/تغییرِ رمزِ admin).
- [ ] دادهٔ پایه (کالا/مشتری/تأمین‌کننده) — دستی یا **ورودِ اکسل** (تنظیمات → ورودِ داده از اکسل).
- [ ] ماندهٔ افتتاحیه ثبت شد (سندِ افتتاحیه).
- [ ] قالب‌های چاپ نصب شد (تنظیمات → قالبِ اسناد → نصبِ قالب‌های پیش‌فرض).
- [ ] پشتیبانِ خودکار فعال و مسیرِ امن تعیین شد.
- [ ] لایسنس فعال شد (یا تریال آگاهانه پذیرفته شد).
- [ ] کاربران/نقش‌ها تعریف شدند.
